# 📝 Todo App

A responsive and user-friendly Todo App built with **HTML, CSS, and JavaScript** to manage daily tasks, set due dates, and save tasks using browser Local Storage.

## 🚀 Live Demo

🔗 **[View Live Todo App](https://mg2658094-hub.github.io/Todo-App/)**

## ✨ Features

* ➕ **Add Tasks:** Create tasks with due dates.
* 🗑️ **Delete Tasks:** Remove tasks when they are no longer needed.
* 💾 **Local Storage:** Save tasks directly in the browser.
* 📱 **Responsive Design:** Works across desktop, tablet, and mobile screens.
* ⚡ **Simple Interface:** Easy-to-use task management.
* 🔄 **Persistent Tasks:** Keep saved tasks after refreshing the page.

## 🛠️ Technologies Used

* **HTML5** — Structures the application.
* **CSS3** — Provides styling and responsive layouts.
* **JavaScript (ES6+)** — Handles task management and DOM manipulation.
* **Local Storage** — Stores tasks in the browser.

## 📌 How to Use

1. Open the [Todo App](https://mg2658094-hub.github.io/Todo-App/).
2. Enter a task in the input field.
3. Select a due date.
4. Click **Add** to create the task.
5. View your tasks in the task list.
6. Click **Delete** to remove a task.
