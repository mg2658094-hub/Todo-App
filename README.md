# 📝 Todo App

A responsive and user-friendly Todo App built with **HTML, CSS, and JavaScript**. It helps users organize daily tasks, set due dates, and save tasks in the browser using Local Storage.

## 🚀 Live Demo

🔗 **[View Live Todo App](https://mg2658094-hub.github.io/Todo-App/)**

## ✨ Features

* ➕ **Add Tasks:** Create new tasks with due dates.
* 🗑️ **Delete Tasks:** Remove tasks when they are completed or no longer needed.
* 💾 **Local Storage:** Save tasks in the browser.
* 📱 **Responsive Design:** Supports desktop, tablet, and mobile screen sizes.
* ⚡ **Simple Interface:** Easy-to-use task management.
* 🔄 **Persistent Tasks:** Saved tasks remain available after refreshing the page in the same browser.

## 🛠️ Technologies Used

* **HTML5** — Structures the application.
* **CSS3** — Provides styling and responsive layouts.
* **JavaScript (ES6+)** — Handles task management and DOM manipulation.
* **Browser Local Storage** — Stores tasks locally.

## 💻 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/mg2658094-hub/Todo-App.git
```

### 2. Navigate to the Project Directory

```bash
cd Todo-App
```

### 3. Run the Application

Open `index.html` in your web browser.

Alternatively, open the project in VS Code and use the **Live Server** extension.

## 📌 How to Use

1. Open the Todo App using the live demo link.
2. Enter a task in the input field.
3. Select a due date.
4. Click the **Add** button to add your task.
5. View your tasks in the task list.
6. Click the **Delete** button to remove a task.

## 💾 Data Storage

This application uses browser Local Storage to save tasks. Your tasks remain available after refreshing the page in the same browser.

**Note:** Tasks are stored separately in each browser and device. They do not automatically synchronize between devices.
